
# Understanding and Creating Line Plots and Scatter Plots Using Seaborn 

## Objective:
- To learn how to create line plots using the Seaborn library 
- To understand what a line plot is and how it represents data over time or other continuous variables.
- To interpret different types of line plots and their implications on data analysis.
- To learn how to create scatter plots using the Seaborn  library
- To understand what a scatter plot is and how it represents the relationship between two variables.
- To interpret different patterns in scatter plots and their implications on data analysis.

     - What is a line plot?
     - Why are line plots useful in data analysis?
   - **Components of a Line Plot**

   - **Understanding Trends**

## Scatter Plots

### 1. Introduction to Scatter Plots
   - **Definition and Purpose**
     - What is a scatter plot?
     - Why are scatter plots useful in data analysis?
   - **Components of a Scatter Plot**
     - X-axis (One of the variables being compared)
     - Y-axis (The other variable being compared)
     - Points (Each point represents an observation with two variable values)

### 2. Interpreting Scatter Plots

   - **Understanding Relationships**
     - Positive vs. Negative correlations
     - Strong vs. Weak correlations
     - Outliers and their impact
   - **Identifying Patterns**
     - Clustering of points
     - Linear vs. Non-linear relationships

### 3. Seaborn 
   - **Basic Plotting Functions**

     - `plt.scatter()`: Creating scatter plots in Matplotlib
